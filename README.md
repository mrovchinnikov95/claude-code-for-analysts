# Claude Code для аналитика данных — стартовый набор

Рабочие шаблоны для встраивания ИИ-агента (Claude Code) в ежедневную работу аналитика: прямой доступ к PostgreSQL, «профессиональная память» через скилл, хуки-гарды качества и ночная отчётность с самопроверкой. Всё выросло из реальной продовой практики, а не из туториалов.

## Что внутри

| Папка | Что там | С чего начать |
|---|---|---|
| `templates/` | Стартовый `CLAUDE.md` аналитика + конфиг MCP к PostgreSQL | 10 минут |
| `skills/analytics-skill-example/` | Скелет скилла: `SKILL.md` + справочники (карта данных, глоссарий метрик, чек-листы валидации) | вечер |
| `hooks/` | Guard-хук: впрыскивает стандарты по типу задачи, детерминированно | 20 минут |
| `automation/` | Ночной отчёт по расписанию с самопроверкой данных (+ грабли macOS/launchd) | вечер |
| `checklists/` | «Пускаем агента в базу безопасно» — 10 проверок до первого запроса | 5 минут чтения |

## Быстрый старт

1. Прочитай `checklists/agent-into-db-safely.md` — до того, как дашь агенту доступ куда-либо.
2. Скопируй `templates/CLAUDE.md` в `~/.claude/CLAUDE.md` (или в корень проекта) и подставь своё.
3. Настрой read-only доступ к базе по `templates/mcp.json`.
4. Разверни скелет скилла из `skills/` и начни наполнять `references/` — по одному факту после каждой задачи.
5. Подключи `hooks/guard.sh` и адаптируй регулярки под свои типы задач.

## Три уровня, если коротко

1. **Доступ к данным (MCP)** — агент перестаёт быть чатом и начинает работать с реальной базой. Строго read-only.
2. **Память (скилл)** — агент перестаёт каждый день забывать, как устроены ваши данные.
3. **Гарды (хуки)** — стандарты качества живут в среде, а не в надежде, что агент «не забудет».

## Принципы безопасности

- Отдельный пользователь БД: `GRANT SELECT`, `statement_timeout`, ничего лишнего.
- Секреты — в Keychain/менеджере секретов, в конфигах только плейсхолдеры.
- «Готово» от агента — гипотеза, пока не проверено исполнением.
- Каждая цифра наружу — проверена до механизма её формирования.
