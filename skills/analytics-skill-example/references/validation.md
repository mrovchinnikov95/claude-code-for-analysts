# Чек-лист перед выдачей результата (агент прогоняет сам)

## Перед любой цифрой наружу
1. Свежесть источника проверена (дата последней загрузки ≥ ожидаемой).
2. Тестовые/служебные записи исключены (пересечение с их списком = 0).
3. Цифра воспроизводится повторным запуском.
4. Методика описана одной строкой рядом с цифрой.
5. Агрегат по назначаемой группе разбит на до/после назначения.
6. Попытка сломать вывод: что сделает его неверным? Проверено данными, не в уме.
7. Явно разделено: «проверил (как)» vs «предполагаю (почему не проверил)».

## Перед «готово» по задаче
1. Код/запрос реально запущен, результат просмотрен глазами.
2. Краевые случаи: пустые значения, дубли, границы периодов.
3. Новые факты о данных записаны в data-map (обязанность конца задачи).
