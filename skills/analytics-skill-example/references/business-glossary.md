# Глоссарий метрик (пример-скелет)

> Единственный источник правды по формулам. Метрика определяется ОДИН раз — здесь. Нет метрики в глоссарии → спроси владельца, не изобретай.

## Выручка (Revenue)
- Формула: `SUM(orders.amount) / 100.0` при `paid_at IS NOT NULL AND status != 'refunded'`.
- Grain: день оплаты (`paid_at::date`), не день создания заказа.
- Исключения: тестовые пользователи (см. data-map), внутренние заказы.
- Владелец: [имя/роль]. Проверено: 2026-07-01.

## Активный пользователь (MAU)
- Формула: уникальные `user_id` с событием из списка [...] за календарный месяц.
- 🔴 НЕ путать с «залогинился» — логин без события активности не считается.
- Владелец: [имя/роль]. Проверено: 2026-07-01.

## Конверсия в оплату
- Формула: платящие / зарегистрированные за когорту регистрации.
- 🔴 Грабли: если членство в сегменте назначается позже регистрации — разбивать «платил до попадания в сегмент» vs «после». Иначе конверсия сегмента раздувается уже-платящими.
