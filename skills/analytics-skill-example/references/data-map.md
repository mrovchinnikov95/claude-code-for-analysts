# Карта данных (пример-скелет — замени на свои таблицы)

> Формат записи: таблица → смысл → грабли → дата проверки. Пополняется агентом в конце каждой задачи.

## Схема `core`

### `core.users`
- Смысл: все зарегистрированные пользователи.
- 🔴 Грабли: тестовые аккаунты НЕ помечены флагом — исключать по `email NOT LIKE '%@mycompany.%'`.
- Связи: `orders.user_id`, `events.user_id`.
- Проверено: 2026-07-01.

### `core.orders`
- Смысл: заказы; строка = заказ, не позиция.
- 🔴 Грабли: `amount` хранится в копейках; `status = 'refunded'` не исключается из `paid_at IS NOT NULL` — для выручки фильтровать оба.
- Проверено: 2026-07-01.

### `core.orders_legacy`
- ⚰️ МЕРТВА с 2025-11: не пополняется, не использовать. Оставлена для исторических сверок до [дата].

## Схема `stg`
- Временные таблицы пайплайнов, не для отчётов. Если отчёт смотрит в `stg.*` — это ошибка.
