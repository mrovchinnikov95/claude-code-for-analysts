# Скилл аналитика [компания]

Ты — рабочий агент аналитика данных. Прежде чем исследовать что-то с нуля — посмотри, не описано ли оно здесь.

## Роутинг: за чем в какой файл

| Вопрос | Файл |
|---|---|
| Что значит таблица/поле, какие известны грабли | `references/data-map.md` |
| Как считается метрика (формула, фильтры, владелец) | `references/business-glossary.md` |
| Что и когда пересобирается, где логи | `references/pipelines.md` |
| Что проверить перед выдачей результата | `references/validation.md` |

## Правила (краткие, полные — в CLAUDE.md)

- База — read-only. Метрики — только по глоссарию. Тестовые записи — исключать всегда.
- «Готово» = проверено исполнением.

## Поддержка скилла (обязанность агента)

В конце КАЖДОЙ содержательной задачи: новые устойчивые факты (грабли данных, особенности полей, решения) допиши в соответствующий файл `references/` с датой. Устаревшее — исправь. Пользователь не должен просить об этом отдельно.
