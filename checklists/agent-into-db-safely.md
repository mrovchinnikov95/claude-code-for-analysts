# Пускаем агента в базу безопасно: 10 проверок до первого запроса

Пройди список сверху вниз. Пункты 1–4 — обязательные, без них не подключай вообще.

1. **Отдельный пользователь БД для агента.** Не твой личный, не сервисный от приложения. `CREATE ROLE readonly_agent LOGIN;`
2. **Только SELECT.** `GRANT USAGE ON SCHEMA ...; GRANT SELECT ON ALL TABLES IN SCHEMA ... TO readonly_agent;` + `ALTER DEFAULT PRIVILEGES` для будущих таблиц. Никаких INSERT/UPDATE/DELETE/DDL — агенту физически нечем менять данные.
3. **Таймаут на уровне пользователя.** `ALTER ROLE readonly_agent SET statement_timeout = '60s';` Агент не чувствует стоимости запроса — таймаут чувствует за него.
4. **Пароль не в файлах.** Агент читает файлы проекта. Пароль — в Keychain/менеджере секретов; в конфиге плейсхолдер, обёртка подставляет при старте. Проверь: `grep -r "password" .` по проекту не находит ничего живого.
5. **Пулер соединений?** Если между агентом и базой PgBouncer/подобное — настройки сессии из строки подключения могут молча теряться. Проверь, что `statement_timeout` реально применяется: `SHOW statement_timeout;` через агентское подключение. Не применяется — переноси в `ALTER ROLE` (пункт 3) или runtime `SET`.
6. **Боевая или реплика?** Тяжёлые исследовательские запросы — на реплику/стейджинг. Агенту в правилах (CLAUDE.md) — «тяжёлое сначала показывай, потом выполняй».
7. **Права на схемы с чувствительным.** Персональные данные, зарплаты, секреты — исключи из GRANT целыми схемами. Агенту не нужно видеть то, что не нужно видеть.
8. **Логирование.** Включи `log_min_duration_statement` для агентского пользователя или хотя бы знай, где смотреть его запросы. Первую неделю просматривай глазами.
9. **Правила в CLAUDE.md.** Read-only, свежесть данных, тестовые записи, глоссарий метрик — агент должен знать правила игры (см. `templates/CLAUDE.md`).
10. **Проверка боем.** Первой задачей дай агенту вопрос, ответ на который знаешь. Сверь не только цифру, но и методику: правильная цифра неправильным путём — худший исход, он маскирует проблему.

После подключения: правило «каждая цифра наружу — проверена до механизма» никуда не девается. Агент ускоряет работу — ответственность остаётся на тебе.
